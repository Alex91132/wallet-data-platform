# Словарь метрик

Каждая метрика — одно определение, одна витрина. Деньги считаются по проводкам (`ledger_entries`),
количества и конверсии — по операциям и событиям. Время — московское, «день» — календарный день по Москве.

## Деньги — `mart_finance_daily`

| Метрика | Определение | Почему так |
|---|---|---|
| GMV покупок | сумма успешных покупок | возвраты не вычитаются — для них отдельная метрика |
| Выручка (fee revenue) | чистое движение по системному счёту `fees`: комиссии мерчантов и вывода минус возвращённые доли комиссий | по проводкам, а не по полю `fee` операций: учитывает возвраты автоматически |
| Расход на кешбэк | списания с системного счёта `cashback` | |
| Чистая выручка | выручка − кешбэк | без затрат на эквайринг и привлечение — их нет в модели |
| Take rate | выручка / GMV покупок | |
| Доля отказов | неуспешные / все операции (кроме кешбэка) | бизнес-отказы и технические вместе; технические — отдельно в `mart_ops_health_hourly` |

## Онбординг и активация — `mart_activation_funnel`, `mart_kyc_form_funnel`

| Метрика | Определение |
|---|---|
| Регистрация | создан пользователь (OLTP) |
| Начал KYC | событие `kyc_started` в первые 30 дней |
| Подал KYC | заявка KYC в первые 30 дней (OLTP) |
| KYC одобрен | решение `approved` в первые 30 дней |
| Пополнил / купил / перевёл | первая успешная операция своего вида в первые 30 дней |
| Активация 30 дней | доля зарегистрированных, сделавших покупку в первые 30 дней |
| Доходимость формы KYC | доля попыток (сессий с `kyc_started`), закончившихся `kyc_submitted`; по версии формы |

Окно в 30 дней — чтобы когорты разного возраста были сравнимы; последние недели периода его ещё не прожили
и в сравнениях каналов учитываются с этой оговоркой.

## Удержание и вовлечённость — `mart_retention_weekly`, `mart_engagement_daily`

| Метрика | Определение |
|---|---|
| Транзакционное удержание недели N | доля когорты (неделя регистрации) с хотя бы одной своей успешной операцией — пополнение, покупка, перевод, вывод — на неделе N; кешбэк и возвраты не считаются (это не действие клиента) |
| DAU / WAU / MAU | зарегистрированные пользователи с `app_open` за день / 7 / 28 дней |
| Липкость | DAU / MAU |

## Эксперимент — `mart_experiment_cashback`

| Метрика | Определение |
|---|---|
| Покупок за 30 дней | успешные покупки в первые 30 дней после регистрации |
| Комиссии − кешбэк | комиссия с покупок минус начисленный кешбэк за те же 30 дней — экономика клиента для сервиса |
| Дни с покупками на днях 31–60 | остаётся ли эффект, когда повышенный кешбэк закончился |

Анализ — разница средних с 95 % бутстреп-интервалом (4 000 повторов); перед анализом — проверка SRM
(dbt-тест `assert_experiment_no_srm`). Единица рандомизации и анализа — пользователь.

## Качество данных — `mart_data_quality_daily`

| Метрика | Определение |
|---|---|
| Доля дублей | доставки с уже виденным `event_id` / все доставки |
| Доля опоздавших | события, пришедшие позже часа после `client_ts` |
| Нарушения контракта | события в DLQ / все отправленные |
